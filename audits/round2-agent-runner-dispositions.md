# Audit round 2, agent runner: dispositions

Findings: [round2-agent-runner.md](round2-agent-runner.md). Date: 2026-10-29.

Tests are in `agent/test/audit.test.ts` (named after the finding they cover) and run offline: local HTTP servers on
127.0.0.1, a fake vault, and keys generated for each run. Each one fails on the code as it was before the fix.

Results: `npm test` 51/51 (20 existing + 31 new). `npm run typecheck` is clean. `tests/run.sh --quick` reports 8 passed,
0 failed, 2 skipped (the sandbox suites, which `--quick` always skips).

**Totals:** 21 fixed, 1 kept (I7). Four of the fixes keep one part, with the reason in the row: M4, L3, I3, I6.

## Compatibility notes

- Command names and flags are unchanged. The additions are `lint` and `--outcomes`.
- `verify` now needs the RPC. The old offline behaviour is `lint`.
- `--help` exits 0. `settle` and `cancel` now exit 1 when the vault did not record what was asked. `--interval`
  below 30 or with a unit suffix is refused.
- Every command, including `status`, checks the RPC's `chain_id` first. A wrong-network RPC fails before anything else.
