# Phase 1 review: README rewrite, verify fail-closed, committed testnet receipts

Scope: the phase 1 change set (new `README.md`, `LICENSE`, `agent/src/main.ts` fail-closed input checks and their
test, wording scrubs in `agent/` and `audits/`, the `tests/README.md` count, the new `deploy/testnet/receipts/`
data, and the `.gitignore` effect). Each README claim was checked against the code, the tests, the committed data
and read-only testnet RPC (`https://rpc.testnet.near.org`). The judge steps were run exactly as written, in a clean
copy of the repository with fresh `npm ci`, with no keys and no `IRON_TRADE_*` variables set.

Method: code reading; the CLI run against crafted inputs (missing, empty, tampered, forged and partial receipt
files); read-only RPC `view_account` and `view_access_key_list` calls. No transactions were sent and no keys were used.

### Phase 1 code changes: verdict

- `receiptsText()` (main.ts:65-70) does what it says. A missing or blank file makes `verify`, `lint` and
  `verify-attestation` throw, and `cli.ts` turns that into exit 1. All six cases were checked by hand, and the new
  test covers them. A directory path also exits 1 (EISDIR).
- Remaining fail-open paths: `verify` with `dry_run` outcomes (P1-2) and with a non-vault contract (P1-3). `lint`
  exits 0 on any canonical JSON (`{}`), which matches its "canonical-form only" description. `verify-attestation`
  on receipts that need no attestation gives `tee_pill: false` and exit 1, which is correct.
- Committed receipts, outcomes and intents: no keys, no host, IP or URL other than the public Binance ticker, and no
  personal data. They hold testnet account ids, MPC-derived secp256k1 **public** keys, signed and since-expired
  intent payloads (deadlines 2026-10-28 17:35 UTC; a signed `token_diff` can't be replayed after its deadline), and
  local model names (`llama3.2:3b`, `qwen2.5:14b`, `qwen3.6:35b-a3b`). None of it lets anyone act as the agent or
  the owner. The files are mode 600 locally, which git ignores, so this is fine. The `receipts-arena` TEE bundles
  contain NEAR's public `app_compose`, with `${VAR}` placeholders only and no values.
- LICENSE: standard MIT text, "Iron Trade contributors", 2026. Fine.
